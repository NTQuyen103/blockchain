# MystiBoxNFT
- `frontend/`   – React + Vite + Tailwind + ethers (chạy: `npm install && npm run dev`)
- `backend/`    – Express (khung)
- `blockchain/` – Hardhat (khung). Sau khi deploy, điền địa chỉ vào `frontend/.env` (VITE_CONTRACT_ADDRESS)


///
chạy frontend:
cd MystiBoxNFT/frontend
npm install
cp .env.example .env
npm run dev
